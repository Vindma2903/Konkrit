# Дельта: основа мобильного приложения

## ADDED Requirements

### Requirement: Тема «Коралл»
Приложение MUST использовать токены темы из `design.md` (цвета, радиусы, типографика)
во всех экранах; значения не дублируются в компонентах.

#### Scenario: Шрифт загружен
- **WHEN** приложение запускается
- **THEN** до загрузки Montserrat показывается экран-заставка, после — первый экран
  без мигания системного шрифта

### Requirement: Базовые компоненты
Приложение MUST содержать компоненты `Button`, `TextField`, `OtpInput`, `SegmentedTabs`,
`Chip`, `SelectableCard`, `RadioRow`, `ScreenHeader`, `FieldError`, `Icon`, повторяющие
макет «UX · UI kit» (`P2-CR-Kit`). Зона нажатия интерактивных элементов MUST быть не менее 44 px.

#### Scenario: Кнопка в состояниях
- **WHEN** кнопка основная и активна
- **THEN** фон `#CC3D3D`, белый текст, высота 56, скругление 999
- **WHEN** кнопка неактивна
- **THEN** фон `#E6E7E8`, текст `#6B7077`, нажатие не срабатывает

#### Scenario: Доступность
- **WHEN** элемент — иконка без подписи (например «Назад»)
- **THEN** у него задан `accessibilityLabel`

### Requirement: Закреплённая кнопка и скролл
Экраны с формой MUST иметь вертикальный скролл всего экрана и кнопку действия, закреплённую
внизу. Если содержимое не помещается, над кнопкой рисуется тень.

#### Scenario: Клавиатура
- **WHEN** открыта клавиатура
- **THEN** активное поле остаётся видимым, кнопка не перекрывает ввод

### Requirement: Слой данных за интерфейсом
Экраны MUST обращаться к данным только через `ApiClient`; прямых вызовов `fetch` и
обращений к мок-данным из экранов быть не должно. Контракт MUST быть описан в
`api/openapi.yaml`.

#### Scenario: Подмена клиента
- **WHEN** вместо `mockApi` подключают другую реализацию `ApiClient`
- **THEN** экраны работают без изменений

### Requirement: Мок не попадает в релиз
Мок-реализация и тестовые данные MUST включаться только при `__DEV__` или явном флаге
окружения.

#### Scenario: Релизная сборка
- **WHEN** собран релиз без флага мока
- **THEN** `mockApi` не подключается, а запуск без реального клиента завершается понятной ошибкой конфигурации
