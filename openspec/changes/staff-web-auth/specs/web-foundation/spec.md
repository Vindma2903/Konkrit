# Дельта: основа веб-приложения и каркас авторизации

## ADDED Requirements

### Requirement: Каркас экрана авторизации
Все шесть экранов MUST использовать один каркас: слева коралловая панель `#CC3D3D` с логотипом «Конкрит», заголовком
«Единая платформа для управляющей компании», пунктами «Заявки жителей в одном окне», «Задачи, акты и чаты», «Аналитика и KPI
по сотрудникам» и подписью «Кабинет сотрудников УК»; справа на фоне `#F4F4F2` белая карточка (максимум 460, отступ 40, радиус 20).

#### Scenario: Ширина 1440
- **WHEN** окно 1440 и шире
- **THEN** две колонки как в макете, карточка по центру правой колонки

#### Scenario: Узкое окно
- **WHEN** ширина меньше 900
- **THEN** левая панель скрыта, над карточкой логотип «Конкрит»; горизонтальной прокрутки нет до ширины 360

#### Scenario: Высокая форма
- **WHEN** форма не помещается по высоте (регистрация)
- **THEN** страница прокручивается, карточка не обрезается

### Requirement: Поля и кнопки
Поля MUST быть высотой 52, радиус 14, фон `#F4F4F2`; основная кнопка — пилюля высотой 56, акцент `#CC3D3D`
(наведение/нажатие `#A82E2E`); ссылки `#A82E2E`; ошибка — `#B3261E` под полем и в `aria-describedby`; зона нажатия не менее 44.

#### Scenario: Доступность
- **WHEN** форма озвучивается
- **THEN** у каждого поля есть связанная подпись (`<label>`), ошибки объявляются (`aria-live`), порядок Tab совпадает с визуальным,
  фокус виден, Enter отправляет форму

#### Scenario: Ошибка отправки
- **WHEN** отправка не удалась
- **THEN** сообщение показано над кнопкой с ролью `alert`, кнопка снова доступна

#### Scenario: Автозаполнение
- **WHEN** браузер подставляет данные
- **THEN** поля имеют корректные `autocomplete` (`username`, `current-password`, `new-password`, `email`, `tel`, `name`)

### Requirement: Мок и контракт
Веб MUST работать без бэкенда на моке за интерфейсом `StaffAuthApi`; контракт описан в `api/openapi.yaml`.

#### Scenario: Тестовые учётные записи мока
- **WHEN** в режиме разработки введены тестовые данные из `web/src/api/mockAuthApi.ts`
- **THEN** можно проверить: успешный вход, ждёт подтверждения, отклонён, неверный пароль, `rate_limited`, занятую почту, недействительную ссылку

#### Scenario: Релизная сборка
- **WHEN** собирается релизный бандл
- **THEN** мока и тестовых учётных записей в нём нет (проверка поиском по бандлу)

### Requirement: Заголовки безопасности
Приложение MUST отдаваться с `Referrer-Policy: no-referrer` и без внешних скриптов; шрифты Montserrat подключаются локально.

#### Scenario: Проверка
- **WHEN** открыты экраны авторизации
- **THEN** запросов к сторонним доменам нет
