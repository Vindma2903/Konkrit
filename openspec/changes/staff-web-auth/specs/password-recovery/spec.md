# Дельта: восстановление пароля

Макеты: «Авторизация: восстановление пароля», «письмо отправлено», «новый пароль» (1440).

## ADDED Requirements

### Requirement: Запрос ссылки
Экран `/forgot` MUST показывать ссылку «Вернуться ко входу» со стрелкой, заголовок «Восстановление пароля», подпись «Укажите
почту, на неё придёт ссылка для создания нового пароля.», поле «Электронная почта» и кнопку «Отправить ссылку».

#### Scenario: Отправка
- **WHEN** введена верная почта и нажата «Отправить ссылку»
- **THEN** открыт `/forgot/sent`, ответ одинаков для известной и неизвестной почты

#### Scenario: Пустая или неверная почта
- **WHEN** почта пуста или не похожа на адрес
- **THEN** запрос не уходит; «Введите почту» либо «Проверьте адрес почты»

#### Scenario: Почта подставлена из входа
- **WHEN** на входе была введена почта
- **THEN** она подставлена в поле

#### Scenario: Слишком часто
- **WHEN** сервер ответил `rate_limited`
- **THEN** «Слишком много попыток. Повторите через [N] мин»

### Requirement: Письмо отправлено
Экран `/forgot/sent` MUST показывать иконку конверта, «Проверьте почту», «Мы отправили ссылку для восстановления на [почта].
Она действует [N] минут.», блок «Письма нет?» с кнопкой «Отправить ещё раз через [N] с» и ссылку «Вернуться ко входу».

#### Scenario: Таймер
- **WHEN** экран открыт
- **THEN** кнопка повтора недоступна и отсчитывает секунды из `retryAfterSec`; по окончании — «Отправить ещё раз»

#### Scenario: Повторная отправка
- **WHEN** нажата «Отправить ещё раз»
- **THEN** уходит один запрос, таймер запускается заново, показано «Письмо отправлено снова»

#### Scenario: Обновление страницы
- **WHEN** страница перезагружена, пока таймер идёт
- **THEN** таймер продолжается с оставшегося времени (метка в `sessionStorage`), а не обнуляется

#### Scenario: Прямой заход
- **WHEN** `/forgot/sent` открыт без отправленного запроса
- **THEN** открыт `/forgot`

#### Scenario: Пример письма
- **WHEN** сборка разработческая с моком и нажата «Открыть пример письма»
- **THEN** открыт `/reset?token=demo`; в релизной сборке кнопки нет

### Requirement: Новый пароль
Экран `/reset?token=…` MUST показывать «Новый пароль», «Придумайте пароль, которого раньше не использовали.», поля «Новый пароль»
и «Повторите пароль» (с показом), три требования («Не короче 8 символов», «Заглавная и строчная буквы», «Хотя бы одна цифра»)
и кнопку «Сохранить пароль».

#### Scenario: Требования
- **WHEN** пользователь вводит пароль
- **THEN** каждое требование сразу отмечается выполненным (иконка и текст, не только цвет; озвучивается «выполнено» / «не выполнено»)

#### Scenario: Сохранение
- **WHEN** все требования выполнены, пароли совпадают и нажата «Сохранить пароль»
- **THEN** пароль сохранён, открыт `/login` с сообщением «Пароль изменён. Войдите с новым паролем»

#### Scenario: Требования не выполнены
- **WHEN** нажата «Сохранить пароль» при невыполненных требованиях
- **THEN** запрос не уходит; фокус на поле, невыполненные требования выделены ошибкой

#### Scenario: Пароли не совпадают
- **WHEN** повтор отличается
- **THEN** «Пароли не совпадают»

#### Scenario: Ссылка недействительна
- **WHEN** сервер ответил `invalid_token` (истекла, уже использована или повреждена) либо токена в адресе нет
- **THEN** вместо формы «Ссылка больше не действует» и кнопка «Запросить новую ссылку» (ведёт на `/forgot`)

#### Scenario: Токен не остаётся в адресе
- **WHEN** экран открыт со ссылкой из письма
- **THEN** токен убирается из адресной строки и истории (`router.replace`), хранится только в памяти экрана

#### Scenario: Нет сети
- **WHEN** запрос не дошёл
- **THEN** «Нет соединения. Проверьте интернет и повторите», введённое сохранено
