# Дельта: выбор категории и адреса заявки

Экраны макета: UX S12 · выбор категории, UX S5 · выбор адреса.

## ADDED Requirements

### Requirement: Лист выбора категории (S12)
Нажатие на поле «Категория» MUST открывать лист снизу с заголовком «Категория», полем «Поиск по категориям» и
списком категорий. Список берётся из `ApiClient.getCategories`. Выбранная категория выделена фоном `#FDECEC`,
жирным текстом и галочкой справа.

#### Scenario: Открытие
- **WHEN** нажато поле «Категория»
- **THEN** открыт лист; если категория уже выбрана, она выделена; фокус на поле поиска не ставится

#### Scenario: Выбор
- **WHEN** нажата категория в списке
- **THEN** лист закрывается, поле «Категория» показывает её название тёмным текстом, ошибка поля (если была) исчезает

#### Scenario: Поиск
- **WHEN** пользователь печатает в поле поиска «топ»
- **THEN** в списке остаются категории, в названии которых есть эта подстрока без учёта регистра («Отопление»)

#### Scenario: Ничего не найдено
- **WHEN** по запросу нет категорий
- **THEN** вместо списка текст «Такой категории нет. Выберите «Другое»»

#### Scenario: Загрузка и ошибка
- **WHEN** список ещё загружается
- **THEN** в листе «Загружаем категории…»
- **WHEN** загрузка не удалась
- **THEN** в листе «Не удалось загрузить категории» и кнопка «Повторить»

#### Scenario: Подсказка и ручной выбор согласованы
- **WHEN** категорию выбрали вручную
- **THEN** подсказка «Похоже на …» не показывается (правило из первого изменения не меняется)

### Requirement: Лист выбора адреса (S5)
Нажатие на поле «Адрес» MUST открывать лист «Адрес заявки» со списком подтверждённых привязок жителя
и кнопкой «Добавить адрес». Строка: иконка метки, адрес и «кв. N», подпись «Основной адрес» (для привязки с
`primary = true`) или «Добавлен жителем». Выбранная выделена `#FDECEC` с галочкой.

#### Scenario: Выбор адреса
- **WHEN** нажата другая привязка
- **THEN** лист закрывается, поле «Адрес» показывает её, выбор действует только для этой заявки

#### Scenario: Основной адрес не меняется
- **WHEN** выбран другой адрес для заявки
- **THEN** привязка с `primary = true` остаётся основной, следующая новая заявка снова начинается с неё

#### Scenario: Одна привязка
- **WHEN** у жителя одна привязка
- **THEN** лист открывается с одной строкой и кнопкой «Добавить адрес»

#### Scenario: Добавить адрес
- **WHEN** нажата «Добавить адрес»
- **THEN** лист закрывается, открывается экран «Ваш дом» (онбординг); черновик заявки остаётся нетронутым

#### Scenario: Привязки ещё на подтверждении
- **WHEN** у жителя только неподтверждённые привязки
- **THEN** список пуст, под полем «Адрес» ошибка «Привяжите квартиру, чтобы отправить заявку» (как и раньше)
