# Дельта: вкладка «Чат» — чаты дома

Макет: «Житель: чаты дома». Заменяет заглушку вкладки «Чат».

## ADDED Requirements

### Requirement: Список чатов
Вкладка «Чат» MUST показывать заголовок «Чаты дома» и карточки чатов, которые вернул `listConversations`: «Весь дом»,
«Подъезд [№]», «Совет дома», «Соседи». Карточка: круг 48 с иконкой по типу чата, название, время последнего сообщения,
строка «Имя Фамилия: сообщение» (одна строка с многоточием), точка непрочитанного.

#### Scenario: Карточка с сообщением
- **WHEN** у чата есть последнее сообщение
- **THEN** показаны название, время и строка «Имя Фамилия: текст»

#### Scenario: Чат без сообщений
- **WHEN** у чата нет сообщений
- **THEN** вместо строки «Сообщений пока нет», точки нет

#### Scenario: Время
- **WHEN** сообщение отправлено сегодня
- **THEN** время «14:05»; вчера — «Вчера»; раньше — «22.11»

#### Scenario: Порядок
- **WHEN** загружен список
- **THEN** чаты дома идут от недавней активности к давней, «Чат с УК» не входит в этот порядок

### Requirement: Непрочитанное
У чата с непрочитанными сообщениями MUST быть красная точка 10 px `#CC3D3D` с подписью «Есть непрочитанные» для читалки,
название жирное (800), строка сообщения 600 тёмным цветом. Прочитанный чат: название 700, строка 500 `#666A70`, точки нет.

#### Scenario: Открыли чат
- **WHEN** житель открыл чат и вернулся к списку
- **THEN** у этого чата точки нет, остальные не изменились

### Requirement: Секция «Управляющая компания»
Под чатами дома MUST быть подпись «Управляющая компания» и строка «Чат с УК» (белая «пилюля» с серой рамкой, иконка
пузыря, коралловый текст `#A82E2E`, шеврон справа, высота 56), открывающая переписку с УК.

#### Scenario: Открыть чат с УК
- **WHEN** нажата «Чат с УК»
- **THEN** открывается переписка с УК

### Requirement: Открытие чата
Нажатие на карточку MUST открывать переписку этого чата.

#### Scenario: Открыть групповой чат
- **WHEN** нажата карточка «Совет дома»
- **THEN** открывается переписка «Совет дома»

### Requirement: Состояния списка
Вкладка MUST показывать: «Загружаем чаты…» при загрузке; «Чатов пока нет» (если сервер вернул пустой список, строка
«Чат с УК» остаётся); при ошибке — «Не удалось загрузить чаты» и «Повторить»; список обновляется жестом «потянуть вниз» и при
возврате на вкладку.

#### Scenario: Ошибка
- **WHEN** загрузка не удалась
- **THEN** «Не удалось загрузить чаты» и «Повторить»; строка «Чат с УК» остаётся доступной

#### Scenario: Возврат на вкладку
- **WHEN** житель вернулся на вкладку «Чат» (например, после чтения чата)
- **THEN** список обновляется, непрочитанное пересчитано
