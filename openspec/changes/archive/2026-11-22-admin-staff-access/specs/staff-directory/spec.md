# Дельта: список сотрудников

Макет: «CRM: сотрудники» (1440).

## ADDED Requirements

### Requirement: Таблица сотрудников
Экран `/staff` MUST показывать заголовок «Сотрудники», кнопку «Роли и права», вкладки («Все», «Заявки на доступ» со счётчиком,
«Отклонённые»), поле поиска «Поиск по сотрудникам», выпадающие списки «Роль», «Дом / участок», «Статус» и таблицу:
«Сотрудник» (аватар, имя, телефон), «Роль», «Дом / участок», «Статус», кнопка «Действия с сотрудником».

#### Scenario: Данные
- **WHEN** загружен список
- **THEN** у сотрудника показаны роль («Диспетчер», «Инженер/куратор», «Исполнитель», «Руководитель»), область («Все дома», «[Дом], подъезды N–N», «[Участок]») и статус («Активен», «В отпуске», «Отключён»)

#### Scenario: Поиск
- **WHEN** введён текст в «Поиск по сотрудникам»
- **THEN** через 300 мс после последнего символа список ищет по имени, телефону и почте без учёта регистра; запрос предыдущего текста отменяется и не перезаписывает новый

#### Scenario: Фильтры
- **WHEN** выбраны роль, дом/участок или статус
- **THEN** список сужается по всем выбранным условиям вместе; «Все» снимает условие

#### Scenario: Ничего не найдено
- **WHEN** по поиску и фильтрам никого нет
- **THEN** «Сотрудники не найдены» и «Сбросить фильтры»

#### Scenario: Загрузка и ошибка
- **WHEN** список загружается или не загрузился
- **THEN** «Загружаем сотрудников…» либо «Не удалось загрузить сотрудников» и «Повторить»

#### Scenario: Подтверждённый сотрудник виден сразу
- **WHEN** администратор подтвердил заявку
- **THEN** сотрудник есть в списке без перезагрузки страницы

### Requirement: Действия с сотрудником
Меню «Действия с сотрудником» MUST содержать «Изменить роль и дома», «В отпуске» / «Вернуть из отпуска», «Отключить доступ» /
«Включить доступ»; пункты соответствуют текущему статусу.

#### Scenario: Изменить роль и дома
- **WHEN** выбран пункт
- **THEN** открывается та же панель, что при подтверждении доступа (карточка, роль, дома, права роли) с кнопкой «Сохранить»; новые роль и дома применяются сразу и видны в списке

#### Scenario: Отключить
- **WHEN** выбран «Отключить доступ» и подтверждён диалогом «Отключить доступ для [Имя]? Сотрудник не сможет войти»
- **THEN** статус «Отключён», действующая сессия сотрудника перестаёт работать при ближайшем запросе, вход отвечает «Доступ закрыт»

#### Scenario: Отпуск
- **WHEN** выбрано «В отпуске»
- **THEN** статус «В отпуске»; вход остаётся возможным

#### Scenario: Последний руководитель
- **WHEN** администратор пытается отключить себя или понизить последнего руководителя
- **THEN** действие отклонено (`last_manager`), «Нельзя отключить последнего руководителя»; пункт «Отключить доступ» у себя скрыт

#### Scenario: Меню с клавиатуры
- **WHEN** фокус на «Действия с сотрудником»
- **THEN** Enter и Пробел открывают меню (`role="menu"`), стрелки переключают пункты, Esc закрывает и возвращает фокус

### Requirement: Доступность таблицы
Таблица MUST быть читаема скринридером.

#### Scenario: Структура
- **WHEN** таблица озвучивается
- **THEN** есть заголовки столбцов, у кнопки действий имя «Действия с сотрудником [Имя]», зона нажатия не менее 44
