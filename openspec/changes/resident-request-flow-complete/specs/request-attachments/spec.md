# Дельта: вложения заявки

Экраны макета: UX S6 · выбор вложения, UX S7a–S7f.

## ADDED Requirements

### Requirement: Добавление вложения (S6)
Нажатие на кнопки «Фото», «Видео» или «Файл» в блоке «Вложения» MUST открывать лист «Добавить вложение» с тремя
действиями: «Снять фото или видео», «Выбрать из галереи» (подпись: «До 10 файлов, видео до 100 МБ»), «Файл»
(подпись: «PDF, DOC, до 20 МБ»). Кнопка «Фото» открывает действие сразу в режиме фото, «Видео» — в режиме видео,
«Файл» — выбор документа, без промежуточного листа.

#### Scenario: Общая кнопка
- **WHEN** нажато поле блока «Вложения» вне трёх кнопок (если такое есть) или иное общее действие
- **THEN** открывается лист из трёх действий

#### Scenario: Камера
- **WHEN** выбрано «Снять фото или видео» и разрешение на камеру получено
- **THEN** открывается камера; снятый файл добавляется в список и сразу начинает загружаться

#### Scenario: Нет разрешения
- **WHEN** пользователь отказал в доступе к камере или галерее
- **THEN** показывается сообщение «Нет доступа к камере. Разрешите его в настройках телефона» (для галереи — «…к фото…») и кнопка «Открыть настройки»

#### Scenario: Галерея
- **WHEN** выбрано «Выбрать из галереи»
- **THEN** можно отметить несколько файлов, но не больше, чем осталось до лимита; выбранные добавляются и загружаются

#### Scenario: Документ
- **WHEN** выбран «Файл»
- **THEN** выбор ограничен PDF, DOC и DOCX

#### Scenario: Отмена выбора
- **WHEN** пользователь закрыл системный выбор без файла
- **THEN** список не меняется, ошибок нет

### Requirement: Ограничения (S7f и правила файлов)
Вложений MUST быть не больше 10. Фото и документы — до 20 МБ, видео — до 100 МБ. Допустимые типы: изображения,
видео, PDF, DOC, DOCX. Значения лежат в одной конфигурации.

#### Scenario: Файл слишком большой
- **WHEN** выбран файл больше лимита
- **THEN** он не добавляется, под блоком вложений сообщение «[имя]: файл больше 20 МБ» (для видео — 100 МБ)

#### Scenario: Недопустимый тип
- **WHEN** выбран файл другого типа
- **THEN** он не добавляется, сообщение «[имя]: такой тип файла не поддерживается»

#### Scenario: Достигнут лимит
- **WHEN** в списке 10 файлов
- **THEN** заголовок блока показывает «Максимум 10», кнопки «Фото», «Видео», «Файл» неактивны, под ними подсказка
  «Чтобы добавить новое, удалите одно из вложений.»

#### Scenario: Выбрано больше, чем помещается
- **WHEN** в списке 8 файлов и из галереи выбрано 5
- **THEN** добавляются первые 2, остальные отбрасываются, показано «Добавлено 2 из 5: максимум 10 вложений»

### Requirement: Блок «Вложения» без файлов (S7a)
Пока файлов нет, под тремя кнопками MUST быть подсказка «Фото и видео до 100 МБ, документы PDF и DOC до 20 МБ.
Вложения необязательны.», заголовок блока показывает «До 10 файлов», подпись под кнопкой отправки — «Можно отправить
без вложений.»

#### Scenario: Пустой список
- **WHEN** вложений нет
- **THEN** список файлов не рисуется, кнопка «Отправить заявку» зависит только от остальных полей

### Requirement: Список файлов (S7b–S7e)
Файлы MUST идти списком друг под другом. Строка: миниатюра 48 (иконка по типу, для фото — само изображение), имя
в одну строку с многоточием, статус, крестик «Удалить вложение» с зоной нажатия 44. Заголовок блока показывает
«N из 10».

#### Scenario: Загружено
- **WHEN** файл загружен
- **THEN** статус «[размер] МБ · загружено» зелёным `#1E6B3A` с галочкой

#### Scenario: Идёт загрузка
- **WHEN** файл загружается
- **THEN** в строке процент (например «35%») и полоса прогресса, вместо крестика кнопка «Отменить загрузку»

#### Scenario: Много файлов
- **WHEN** файлов столько, что экран не помещается
- **THEN** прокручивается весь экран целиком, вложенного скролла нет, виден индикатор прокрутки, над кнопкой отправки тень

#### Scenario: Удаление
- **WHEN** нажат крестик у загруженного файла
- **THEN** файл исчезает из списка, счётчик уменьшается; если был достигнут лимит, кнопки добавления снова активны

#### Scenario: Отмена загрузки
- **WHEN** нажата «Отменить загрузку»
- **THEN** загрузка прерывается и файл убирается из списка

### Requirement: Загрузка и очередь
Загрузка начинается сразу после выбора. Одновременно MUST идти не больше 3 загрузок, остальные ждут и показывают
0%. Каждая загрузка вызывает `ApiClient.uploadAttachment` с прогрессом и отменой.

#### Scenario: Очередь
- **WHEN** выбрано 5 файлов
- **THEN** три загружаются, два ждут; как только одна завершилась, стартует следующая

### Requirement: Ошибки загрузки (S7c)
Файл, который не загрузился, MUST показывать «Не загрузилось · нет связи» красным `#B3261E` и кнопку «Повторить» на
самой строке. Над списком показывается плашка «Не загрузилось: N файла. Нет связи.» с кнопкой «Повторить все».

#### Scenario: Часть не загрузилась
- **WHEN** два файла из пяти не загрузились
- **THEN** у них в строках «Не загрузилось · нет связи» и «Повторить»; плашка «Не загрузилось: 2 файла. Нет связи.»;
  остальные показывают свой статус; склонение: 1 файл, 2 файла, 5 файлов

#### Scenario: Повторить один
- **WHEN** нажата «Повторить» на строке
- **THEN** файл снова загружается, его строка показывает процент

#### Scenario: Повторить все
- **WHEN** нажата «Повторить все»
- **THEN** все файлы с ошибкой ставятся в очередь заново; плашка исчезает, как только ошибок не осталось

#### Scenario: Удалить файл с ошибкой
- **WHEN** нажат крестик у файла с ошибкой
- **THEN** файл удаляется, плашка пересчитывается

### Requirement: Кнопка отправки и вложения (S7b–S7d)
Кнопка «Отправить заявку» MUST быть неактивна, пока есть файлы в состоянии «идёт загрузка» или «не загрузилось».
Подпись под кнопкой: «Дождитесь окончания загрузки вложений.» при загрузке, «Повторите загрузку или удалите файлы с
ошибкой.» при ошибке, иначе «Заявку получит диспетчер. Статус придёт в MAX и push.».

#### Scenario: Все загружено
- **WHEN** все файлы загружены и остальные поля верны
- **THEN** кнопка активна, подпись стандартная (S7d)

#### Scenario: Приоритет подписи
- **WHEN** есть и загружающиеся, и неудавшиеся файлы
- **THEN** показывается подпись про ошибку
